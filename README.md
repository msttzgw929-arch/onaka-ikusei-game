# お腹育成ゲーム

ブラウザで遊べる1ページゲーム。ごはんを食べさせ、お腹をマッサージして、お姉さんのお腹を部屋サイズ → ビル → 山 → 地球 → 宇宙の果ての先までどこまでも育てます。

## 起動方法
音声・画像を読み込むため、ローカルWebサーバ経由で開いてください（file:// 直開きは不可）。

    cd onaka-game
    python3 -m http.server 8000
    # ブラウザで http://localhost:8000/ を開く

## 操作
- ごはんカードをタップ、または口元／お腹へドラッグして食べさせる
- お腹をなでる（ドラッグ）とマッサージ：満腹度が下がり、お腹が育つ
- お腹・顔をタップで反応
- 強化タブ：食欲アップ／胃袋拡張／マッサージ上達／専属シェフ（自動給餌）／全自動エステ（自動消化）
- 進行は localStorage に自動保存（メニュー → リセット可）
- デバッグ（早送り）：URLに `?debug` を付ける、または Shift+D / F9

## クレジット
- 音声合成：AivisSpeech（Style-Bert-VITS2）
- 音声モデル：みちのくあいり（こずかた学園プロジェクト / Aivis Project・声：上戸恵里）ACML 1.0　※非公式の二次利用
- キャラクター：ユーザー提供イラスト（背景除去・表情差分は加工）
- SE・BGM・背景：すべてプロシージャル生成（WebAudio / Canvas）

## 構成
- index.html, css/, js/（char.js: WebGLキャラ＋お腹シェーダ, face.js: 表情, bg.js: 世界, audio.js: 音, data.js: 数値, game.js: 本体）
- assets/img（切り抜き・顔パーツ）, assets/voice（音声 mp3 + voices.json）
- tools/（素材生成・テスト用スクリプト。ゲーム実行には不要）
- screenshots/（各ステージのスクショ）
